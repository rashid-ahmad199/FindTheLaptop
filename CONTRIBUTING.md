# Feedback and Bug Reports

Find the Laptop is developed and maintained only by its author, Rashid Ahmad. It is **not** an open-source project (see [LICENSE](LICENSE)).

## Pull requests are not accepted

Please do not open pull requests or send code. They will be closed without review. This keeps the tool consistent and safe, because it can run as Administrator.

## What is welcome

- Bug reports and wrong results (use the issue templates).
- Ideas for new checks, especially for fake or tampered laptops.
- Test results on different laptop brands and Windows versions (without personal data).

Your suggestions may be used by the author without payment or credit.

## Before you report

- The tool targets **Windows 10 and 11**. Please say which version you use.
- Security problems: do **not** open a public issue. Follow [SECURITY.md](SECURITY.md).

## Privacy

Never attach a full report to an issue. It contains the serial number and Windows product key. Remove or blur them first.
