# Security Policy

Find the Laptop reads system information and can, with explicit approval, change system settings and quarantine files. Security reports are taken seriously.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

1. Use GitHub's private reporting: **Security tab → Report a vulnerability**.
2. If that is unavailable, open a public issue titled "Security contact request" **without any details** and the author will arrange a private channel.

Include the version, Windows version, steps to reproduce and the impact. You will get a reply as soon as possible.

## Scope examples

- The Cleaner's local server accepting requests it should reject.
- An action running without user approval.
- A path or command injection through scanned file names or registry values.
- A report leaking data it should not.

## Supported versions

Only the latest release receives fixes.
